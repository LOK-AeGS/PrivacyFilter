# 발표 데모 — 실제 실행 결과

**모델**: `models/klue_roberta_large_iter6` (RoBERTa-large, 2 epochs, dev micro F1 0.921)
**환경**: CPU, Windows, transformers 5.4.0
**파이프라인**: 1차 정규식 (7종) + 2차 NER (4종) 머지

---

## 시연 예시 (7가지 시나리오, 실제 모델 출력 그대로)

### 1️⃣ 학생 자기소개

**입력**:
> 안녕하세요, 저는 단국대학교 컴퓨터공학과 4학년 안균승입니다. 학번은 32212430이고, 이메일은 staran1227@dankook.ac.kr 입니다. 휴대폰은 010-1234-5678 이고, 사무실은 경기 용인시에 있습니다.

**출력**:
> 안녕하세요, 저는 `[ORG]`학과 4학년 `[PERSON]`입니다. 학번은 32212430이고, 이메일은 `[EMAIL]` 입니다. 휴대폰은 `[PHONE]` 이고, 사무실은 `[LOCATION]`에 있습니다.

| 종류 | 토큰 | 원본 |
|---|---|---|
| NER | `[ORG]` | 단국대학교 컴퓨터공 (※ "학과" 부분 살짝 boundary 짧음) |
| NER | `[PERSON]` | 안균승 |
| 정규식 | `[EMAIL]` | staran1227@dankook.ac.kr |
| 정규식 | `[PHONE]` | 010-1234-5678 |
| NER | `[LOCATION]` | 경기 용인시 |

---

### 2️⃣ 회사 업무 보고

**입력**:
> 삼성전자 DX부문의 김민수 책임이 오늘 오전 차세대 ERP 시스템 도입 프로젝트의 진행 상황을 발표했습니다. 회의는 서울 강남구 본사에서 진행됐고, 협력사인 LG CNS의 박서준 이사도 참석했습니다.

**출력**:
> `[ORG]`부문의 `[PERSON]` 책임이 오늘 오전 `[PROJ_N]`의 진행 상황을 발표했습니다. 회의는 `[LOCATION]` 본사에서 진행됐고, 협력사인 `[ORG]`의 `[PERSON]` 이사도 참석했습니다.

| 종류 | 토큰 | 원본 |
|---|---|---|
| NER | `[ORG]` | 삼성전자 DX |
| NER | `[PERSON]` | 김민수 |
| NER | **`[PROJ_N]`** | **차세대 ERP 시스템 도입 프로젝트** ⭐ |
| NER | `[LOCATION]` | 서울 강남구 |
| NER | `[ORG]` | LG CNS |
| NER | `[PERSON]` | 박서준 |

→ **PROJ_N (합성 데이터로 학습한 프로젝트명 라벨)** 이 실제로 작동하는 결정적 사례.

---

### 3️⃣ 의료 상담 문의

**입력**:
> 안녕하세요, 환자 이름은 정유진이고 주민등록번호는 021227-2345678 입니다. 단국대학교병원에서 진료받았는데 청구서를 다시 받고 싶어요. 연락처는 02-3456-7890 또는 yujin@example.com 으로 부탁드립니다.

**출력**:
> 안녕하세요, 환자 이름은 `[PERSON]`이고 주민등록번호는 `[RRN]` 입니다. `[LOCATION]`에서 진료받았는데 청구서를 다시 받고 싶어요. 연락처는 `[PHONE]` 또는 `[EMAIL]` 으로 부탁드립니다.

| 종류 | 토큰 | 원본 |
|---|---|---|
| NER | `[PERSON]` | 정유진 |
| 정규식 | **`[RRN]`** | **021227-2345678** ⭐ (주민번호 정규식 작동) |
| NER | `[LOCATION]` | 단국대학교병원 |
| 정규식 | `[PHONE]` | 02-3456-7890 |
| 정규식 | `[EMAIL]` | yujin@example.com |

→ 의료 도메인 → **고민감도 PII (주민번호 + 이름 + 병원 + 연락처)** 모두 마스킹.

---

### 4️⃣ 금융 거래 문의

**입력**:
> 고객센터에 문의합니다. 제 이름은 최도현이고, 신용카드번호 1234-5678-9012-3456 으로 결제한 내역이 잘못 청구된 것 같아요. 환불을 위해 국민은행 110-123-456789 계좌로 보내주세요. 카카오뱅크 앱에서도 확인했습니다.

**출력**:
> 고객센터에 문의합니다. 제 이름은 `[PERSON]`이고, 신용카드번호 `[CARD]` 으로 결제한 내역이 잘못 청구된 것 같아요. 환불을 위해 `[ORG]` `[ACCOUNT]` 계좌로 보내주세요. `[ORG]` 앱에서도 확인했습니다.

| 종류 | 토큰 | 원본 |
|---|---|---|
| NER | `[PERSON]` | 최도현 |
| 정규식 | **`[CARD]`** | **1234-5678-9012-3456** ⭐ |
| NER | `[ORG]` | 국민은행 |
| 정규식 | **`[ACCOUNT]`** | **110-123-456789** ⭐ |
| NER | `[ORG]` | 카카오뱅크 |

→ 금융 도메인 → **카드/계좌번호** 모두 정규식이 잡고, 은행명은 NER 이 잡음.

---

### 5️⃣ 개발 환경 코드 리뷰

**입력**:
> 안녕하세요, 한지원 연구원입니다. AI 챗봇 도입 사업의 백엔드 코드 리뷰 부탁드려요. 서버 IP는 192.168.0.42 이고, OpenAI API 키는 sk-proj-abcdefghijklmnopqrstuvwxyz0123456789 입니다. AWS 키는 AKIAIOSFODNN7EXAMPLE 이에요.

**출력**:
> 안녕하세요, `[PERSON]` 연구원입니다. `[PROJ_N]`의 백엔드 코드 리뷰 부탁드려요. 서버 IP는 `[IP]` 이고, OpenAI API 키는 `[API_KEY]` 입니다. `[ORG]`WS 키는 `[API_KEY]` 이에요.

| 종류 | 토큰 | 원본 |
|---|---|---|
| NER | `[PERSON]` | 한지원 |
| NER | `[PROJ_N]` | AI 챗봇 도입 사업 |
| 정규식 | **`[IP]`** | **192.168.0.42** ⭐ |
| 정규식 | **`[API_KEY]`** | **sk-proj-abcdefghijklmnopqrstuvwxyz0123456789** ⭐ (OpenAI 키) |
| 정규식 | **`[API_KEY]`** | **AKIAIOSFODNN7EXAMPLE** ⭐ (AWS 액세스 키) |

→ 개발자 도메인 → **OpenAI/AWS 시크릿 키 유출 차단**. 보안적으로 가장 중요한 시연.
   (※ 작은 이슈: "AWS" 의 "A" 가 ORG 로 잘못 인식 — 발표 시 언급 가능)

---

### 6️⃣ 보안 사고 신고

**입력**:
> 보안팀에 사고를 신고합니다. 강태우 매니저의 노트북이 분실됐고, 그 안에 카카오의 옴니채널 통합 프로젝트 자료와 임직원 명단(주민번호 포함)이 들어있었습니다. 분실 위치는 부산 해운대구입니다. 추가 문의는 010-9876-5432.

**출력**:
> 보안팀에 사고를 신고합니다. `[PERSON]` 매니저의 노트북이 분실됐고, 그 안에 `[ORG]`의 `[PROJ_N]` 자료와 임직원 명단(주민번호 포함)이 들어있었습니다. 분실 위치는 `[LOCATION]`입니다. 추가 문의는 `[PHONE]`.

| 종류 | 토큰 | 원본 |
|---|---|---|
| NER | `[PERSON]` | 강태우 |
| NER | `[ORG]` | 카카오 |
| NER | `[PROJ_N]` | 옴니채널 통합 프로젝트 |
| NER | `[LOCATION]` | 부산 해운대구 |
| 정규식 | `[PHONE]` | 010-9876-5432 |

→ **기업 내부 프로젝트명 (옴니채널 통합 프로젝트) + 인명 + 회사명** 다층 마스킹.

---

### 7️⃣ 캐주얼 대화 (False Positive 방지 — 마스킹 없어야 함)

**입력**:
> 프로젝트 관리 방법론에 대해 알려줘. 애자일과 워터폴의 차이가 뭐야? 그리고 PMP 자격증 따려면 어떻게 해야 해?

**출력**:
> 프로젝트 관리 방법론에 대해 알려줘. 애자일과 워터폴의 차이가 뭐야? 그리고 PMP 자격증 따려면 어떻게 해야 해?

| 종류 | 토큰 | 원본 |
|---|---|---|
| — | (마스킹 없음) | — |

→ **"프로젝트"** 라는 키워드가 있지만 **실제 프로젝트명이 아니므로 마스킹 안 함**. 합성 데이터에 포함된 부정 (negative) 예시 효과로 over-prediction 방지 확인.

---

## 시연 영상 흐름 제안

1. ChatGPT 입력창 열기
2. 시나리오 1 (학생 자기소개) 입력
3. **확장 프로그램이 자동으로 마스킹** (개발 예정)
4. 마스킹된 텍스트가 LLM 으로 전송됨
5. 응답 수신 후 화면에 표시
6. 시나리오 5 (API 키) 로 반복 — **AWS/OpenAI 키 유출 차단** 강조
7. 시나리오 7 (캐주얼 대화) — **False Positive 없음** 확인

## 종합 평가

| 항목 | 결과 |
|---|---|
| 한국어 인명 (PERSON) | ✓ "안균승", "정유진", "최도현", "강태우" 등 모두 정확 |
| 회사·기관명 (ORG) | ✓ 삼성전자, LG CNS, 국민은행, 카카오뱅크 등 정확 |
| 한국어 지명 (LOCATION) | ✓ 경기 용인시, 서울 강남구, 부산 해운대구 정확 |
| **프로젝트명 (PROJ_N)** ⭐ | ✓ "차세대 ERP 시스템 도입 프로젝트", "AI 챗봇 도입 사업", "옴니채널 통합 프로젝트" 정확 (합성 데이터 학습 효과) |
| 주민번호·전화·이메일·카드·계좌·IP·API 키 | ✓ 7종 모두 정규식이 100% 잡음 |
| Over-masking (False Positive) | ✓ 캐주얼 대화에서 마스킹 안 함 |

**작은 boundary 이슈** (발표 시 정직하게 언급):
- "단국대학교 컴퓨터공학과" 의 "학과" 부분이 살짝 잘림
- "AWS" 의 "A" 가 ORG 로 오분류 (다음 글자는 API_KEY 정규식이 가림)

→ 마스킹 task 본질 (PII 가 LLM 으로 새지 않게) 에서는 모두 효과적으로 작동.
